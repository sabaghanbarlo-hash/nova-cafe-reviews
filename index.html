About this demo

Nova Café's Reputation Manager is a fully self-contained portfolio demo. Everything — review requests, star ratings, written feedback, categorization, and response drafting — runs locally in the browser using localStorage. Nothing is sent to a server, and no paid API keys are required.

Ready to go live? This exact flow can be connected to real tools when a client is ready:

  • Google Business Profile API — to post/read real Google reviews
  • WhatsApp Business API / Twilio SMS — to send real review-request messages
  • An LLM API (e.g. Claude) — to generate richer, more nuanced response drafts
  • A real database (e.g. Supabase/Firebase) — to persist data beyond one browser
